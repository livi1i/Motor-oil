# Motor Oil

Статический сайт: каталог масел, услуги СТО, автомойка, фотоотзывы и карта адресов.

## Запуск

Открывайте через HTTP-сервер, например `python -m http.server 57005`, затем http://localhost:57005/. Сборка для публикации не требуется. Пакеты npm нужны только для инструментов разработки Magic UI MCP.

## GitHub Pages

Публикация из ветки main, папка / (root). Все локальные ресурсы используют относительные пути, совместимые с адресом /Motor-oil/. Вместе с index.html необходимо публиковать src/, assets/, public/ и используемые JSON в data/.

Каталог: public/data/oils-catalogue.json. Адреса: data/research/locations.json. Фотоотзывы с источниками: data/reviews/photo-reviews.json. Изображения услуг назначены в src/app.js.

Сайт остаётся демо-концептом с noindex/nofollow. Обращения подготавливаются локально и отправляются пользователем через ВКонтакте.
